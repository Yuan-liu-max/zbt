# 珠宝通系统 — 阿里云服务器部署指南

> 本文档从零开始，详细说明如何将三端（后端 + 管理端 + 商城端）部署到阿里云服务器。

---

## 一、前提准备

### 1. 本地打包产物

```bash
# 后端打包（在本地执行）
cd backend/zb-tong-server
mvn clean package -DskipTests
# 产物：target/zb-tong-server-1.0.0-SNAPSHOT.jar

# 前端管理端打包
cd frontend
npm run build
# 产物：dist/

# 商城端打包
cd shop
npm run build
# 产物：dist/
```

### 2. 服务器配置建议

| 项目 | 最低配置 |
|------|---------|
| 操作系统 | CentOS 7+ / Ubuntu 20.04+ / Alibaba Cloud Linux |
| CPU | 2 核 |
| 内存 | 4GB（Java + MySQL + Redis + Nginx） |
| 磁盘 | 40GB+ |

---

## 二、阿里云安全组配置

登录阿里云控制台 → ECS 实例 → 安全组 → 添加规则：

| 端口 | 协议 | 授权对象 | 用途 |
|------|------|---------|------|
| 22 | TCP | 你的IP | SSH 远程登录 |
| 80 | TCP | 0.0.0.0/0 | HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS |

> ⚠️ **不要开放 3306（MySQL）和 6379（Redis）**，它们只走内网 127.0.0.1。

## 三、服务器环境安装

### 1. 安装 JDK 8

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y openjdk-8-jdk

# CentOS
sudo yum install -y java-1.8.0-openjdk-devel

# 验证
java -version
```

### 2. 安装 MySQL 8.0

```bash
# Ubuntu
sudo apt install -y mysql-server
sudo systemctl enable mysql
sudo systemctl start mysql

# 设置 root 密码
sudo mysql -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的强密码';"
```

### 3. 安装 Redis（可选，若 LoginRateLimiter 依赖 Redis）

```bash
sudo apt install -y redis-server
sudo systemctl enable redis
sudo systemctl start redis

# 设置密码
# 编辑 /etc/redis/redis.conf，取消注释 requirepass 并设置密码
```

### 4. 安装 Nginx

```bash
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
```

## 四、数据库初始化

### 1. 创建生产数据库

```bash
mysql -u root -p

CREATE DATABASE zb_tong DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

### 2. 执行迁移脚本（47 个）

将本地的 `backend/zb-tong-server/src/main/resources/db/migration/` 目录上传到服务器，然后：

```bash
# 上传迁移文件（本地执行）
scp -r backend/zb-tong-server/src/main/resources/db/migration/ root@服务器IP:/root/migration/

# 服务器上执行（按版本号顺序）
cd /root/migration
for f in $(ls V*.sql | sort -V); do
  mysql -u root -p zb_tong < "$f" || { echo "失败: $f"; break; }
done
```

### 3. 创建管理员账号

> ⚠️ V8 的 admin 种子已注释（安全考虑），需手动创建。

```bash
mysql -u root -p zb_tong
```

```sql
-- 创建 admin 账号（密码先用下面占位，上线后立即改）
-- 密码 "Admin@2026" 的 BCrypt 哈希（用下方 SQL 后立即修改密码）
INSERT INTO sys_user (id, username, password_hash, real_name, phone, status, is_deleted)
VALUES (1, 'admin', '<BCrypt哈希>', '系统管理员', '13800000000', 'ENABLED', 0);

-- 绑定 ADMIN 角色（role_id=1 是 ROLE_ADMIN）
INSERT INTO sys_user_role (user_id, role_id) VALUES (1, 1);
```

**生成 BCrypt 哈希的方法**（二选一）：
- 方案A：临时把 V8 的 admin 哈希 `$2b$10$BLVuYbMyQWZFLS3i1cBGo.ziBfANuXogm4BXvkqGjra/los2Kn1z6`（密码 admin123）填入，上线后**立即通过系统改密码**。
- 方案B：用在线工具（如 bcrypt-generator.com）生成强密码的 BCrypt 哈希。

## 五、后端部署

### 1. 上传 jar 到服务器

```bash
# 本地执行
scp backend/zb-tong-server/target/zb-tong-server-1.0.0-SNAPSHOT.jar root@服务器IP:/opt/zbtong/
```

### 2. 创建启动脚本

服务器上创建 `/opt/zbtong/start.sh`：

```bash
#!/bin/bash
cd /opt/zbtong
nohup java -jar zb-tong-server-1.0.0-SNAPSHOT.jar \
  --spring.profiles.active=prod \
  -DDB_HOST=127.0.0.1 \
  -DDB_USERNAME=root \
  -DDB_PASSWORD=你的数据库密码 \
  -DREDIS_HOST=127.0.0.1 \
  -DREDIS_PASSWORD=你的Redis密码 \
  -DJWT_SECRET=一个很长的随机密钥至少32位 \
  -DOPENAI_API_KEY=你的OpenAI密钥 \
  > /opt/zbtong/app.log 2>&1 &
echo $! > /opt/zbtong/app.pid
```

```bash
chmod +x /opt/zbtong/start.sh
```

### 3. 配置 systemd 开机自启（推荐）

创建 `/etc/systemd/system/zbtong.service`：

```ini
[Unit]
Description=ZbTong Backend Service
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/zbtong
Environment="DB_HOST=127.0.0.1"
Environment="DB_USERNAME=root"
Environment="DB_PASSWORD=你的数据库密码"
Environment="REDIS_HOST=127.0.0.1"
Environment="REDIS_PASSWORD=你的Redis密码"
Environment="JWT_SECRET=你的JWT密钥"
Environment="OPENAI_API_KEY=你的OpenAI密钥"
ExecStart=/usr/bin/java -jar /opt/zbtong/zb-tong-server-1.0.0-SNAPSHOT.jar --spring.profiles.active=prod
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable zbtong
sudo systemctl start zbtong

# 查看状态
sudo systemctl status zbtong
# 查看日志
journalctl -u zbtong -f
```


## 八、验证清单

部署完成后逐项验证：

- [ ] 后端启动成功：`systemctl status zbtong` 显示 active
- [ ] 后端健康：`curl http://localhost:8080/api/actuator/health`
- [ ] 管理端访问：`https://你的域名/admin/` 能打开登录页
- [ ] 商城端访问：`https://你的域名/h5/` 能打开首页
- [ ] 登录功能：用 admin 账号能登录管理端
- [ ] Cookie Secure：登录后 F12 查看 Cookie 带 Secure 标志
- [ ] API 文档已关闭：`/api/doc.html` 返回 404
- [ ] 日志无敏感信息：`journalctl -u zbtong` 无 SQL、无 apiKey

## 九、常见问题

### Q1：后端启动失败 "JWT_SECRET 不能为空"
说明未注入 JWT_SECRET 环境变量，检查 systemd 配置或启动脚本。

### Q2：前端页面能打开但 API 404
检查 Nginx 是否配置了 `/api` 反向代理，且后端 context-path 是 `/api`。

### Q3：图片显示不了
检查 Nginx 是否配置了 `/files` 和 `/images` 的代理。

### Q4：登录后刷新又跳回登录页
检查 Cookie 的 Secure 标志与 Nginx 的 HTTPS 配置是否一致（HTTPS 下 Cookie 必须 Secure）。
